# Project Overview

This project involves the development of a comprehensive business website for **Mo' The Picnic Guru**, a luxury picnic setup and event décor company based in Limpopo, South Africa. The business specialises in elegant picnic experiences, romantic setups, birthday celebrations, luxury event styling, kiddies themed parties, venue décor, and personalised celebration experiences tailored to different customer needs.

The website was developed to establish a professional online presence for the business while showcasing the unique décor services offered by the company. The digital platform serves as a modern marketing and communication tool that allows potential customers to explore services, browse previous event setups, enquire about bookings, and interact with the brand online.

The development process focused on combining modern web technologies with luxury feminine aesthetics to create a visually appealing, responsive, and user-friendly website experience. The website reflects the business identity through carefully selected shades of pink, nude, beige, and brown tones that communicate elegance, sophistication, warmth, and creativity.

The Mo' The Picnic Guru website development project was completed over multiple phases involving planning, design, development, testing, responsiveness optimisation, styling enhancement, and JavaScript interactivity implementation. Throughout the project, attention was placed on user experience, visual hierarchy, responsive design principles, accessibility, and professional presentation standards.

The website was developed using HTML5, CSS3, and JavaScript, while GitHub was used for version control and repository management. The project demonstrates the practical implementation of front-end web development concepts, responsive web design, modern styling techniques, and interactive functionality.

* **Portfolio Presentation**
  To create an organised gallery that highlights previous décor setups and showcases the company’s creativity and design capabilities.

  To ensure that the website functions effectively across mobile phones, tablets, laptops, and desktop devices.

# Responsive Design Implementation

The following breakpoints were implemented:
